Далее необходимо ввести тестовые данные для алгоритма. Немного комментарий по поводу ввода:

1) Пример ввода показан в файле my_test.txt, там считается, что начальная вершина вводится первой

2) Я отказалась от вывода в формате "PATH х1 ЗАЛ-А OK" после LOOK, поэтому теперь важно передавать информацию о каждом ребре на LOOK в том же порядке, в котором ребра вводились в начале задачи (сделано так в силу нехватки времени)

3) Также при вводе данных необходимо сообщить количество вершин и ребер (подробнее смотри файл my_test.txt), поэтому не нужно писать vertex, edge перед данными. Также отменена функция entrance, считается, что первая вершина, которую указали, будет являться entrance.

4) В коде также нет проверки корректности ввода пользователя (в силу нехватки времени)

*Описание алгоритма в целом:*

Сначала мы проходимся по всем вершинам, до которых можем достать без CLEAR. Это все обходится бесплатно и мы только увеличиваем доход. При этом мы запоминаем все вершины, которые мы почти смогли достигнуть, то есть они отделены от компоненты, где все связано через OK-ребра ребром BROKEN (то есть если сделаем CLEAR одного ребра, то сможем попасть в эти вершины). Теперь у нас появились кандидаты на вершины, к которым можно сделать CLEAR. Нам нужно для каждоый вершины понять, какое мат.ожидание от нее получится, то есть в среднем сколько буста даст вершина к зарплате, к какой из вершин выгоднее всего пойти. Для этого мы вычисляем: cost(вершины) - зарплата для горняков в день + $\sum$ по вершинам, которые можем достигнуть из этой вершины. При этом реальный LOOK запускать нельзя, поэтому будем считать мат.ож с помощью вероятностей. Нужно пройтись по всему подграфу, который еще не был пройден. Таким образом, мы сможем выявить лучшую вершину с помощью мат.ожидания. Тогда потом из начальной вершины дойдем до нее по OK-нутым вершинам и сделаем CLEAR, а дальше еще раз будем ходить бесплатно, пока это возможно. При этом, если вдруг все новые вершины можно открыть только с отрицательной стоимостью, то не будем туда лезть, так как работать в минус не хочется.
